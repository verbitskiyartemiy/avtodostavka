# Автодоставка

Студенческий проект: приложение для покупки автомобилей из Кореи, Японии и Китая.

Проект прорабатывается автономным пайплайном Claude Code по шагам Discovery Kit — см. `CLAUDE.md`, `PIPELINE.md`, прогресс в `STATUS.md`. Итог — `SUMMARY.md` и бриф презентации в `presentation/`.

Рабочая ветка: `claude/discovery`.
