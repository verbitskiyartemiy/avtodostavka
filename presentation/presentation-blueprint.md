## 0. Общие требования к оформлению (из ТЗ, раздел 2, и шаблона)

| # | Требование | Как сделать |
|---|---|---|
| 1 | Все слайды пронумерованы | Номер в правом нижнем углу, 14–16 pt, на всех 11 слайдах, включая титульный |
| 2 | Контраст для проектора в светлой аудитории | Тёмный текст (#1A1A1A или тёмно-синий #1F2A44) на белом или очень светлом фоне. **Никакого светло-зелёного и вообще бледного шрифта на белом.** Акцентный цвет — один, насыщенный и тёмный (например, тёмно-синий #1F4E9A или тёмно-красный #A01C1C для «потерь»). Серый для источников — не светлее #555555 |
| 3 | Один слайд = одна мысль | На слайде одна цифра-акцент и один визуал. Всё второстепенное — в заметки спикера или по QR |
| 4 | Заголовок — вывод, а не тема | Заголовки ниже уже сформулированы как выводы с цифрой. Не заменять на «Проблема», «Решение» и т.п. Название раздела можно дать маленькой плашкой над заголовком (например, «ПРОБЛЕМА») |
| 5 | Большие таблицы и исследования — по QR | На слайде ключевой вывод + QR на полную версию. Таблица на слайде — максимум 6 строк × 6 столбцов. Какие документы выкладывать — `presentation/qr-materials.md`. Не больше одного QR на слайд, всего 5 |
| 6 | «Команда» — первым или последним | Ставим вторым, сразу после титульного (по составу слайдов ТЗ) |
| 7 | Порядок истории | проблема → решение → технология → рынок и конкуренты → ЦА → деньги → гипотезы → план → что сделано |
| 8 | Источники | Внизу каждого слайда с цифрами, мелко (10–12 pt, серый не светлее #555555), в формате «Название, URL, дата». В тексте слайда рядом с цифрой — надстрочная ссылка [1], [2]… на строку источника. Длинные URL можно сократить до домена + путь в заметках, но в файле-исходнике держать полные |
| 9 | Пометки «Гипотеза» / «Допущение» / «Симуляция» | Маленькая плашка с тёмным текстом на светлом фоне (например, чёрный текст на светло-жёлтом #FFF4CC с тёмной рамкой) рядом с цифрой или блоком. Слово целиком, не иконкой |
| 10 | Шрифты | Заголовок ≥ 32 pt, основной текст ≥ 18 pt, цифра-акцент 60–96 pt, источники 10–12 pt. Читается с 5 метров |
| 11 | Скрины прототипа | Вайрфреймы из `discovery/wireframes/` перерисовать как чистые мобильные макеты (серые плашки, без выдуманных логотипов). Подпись под каждым: «Прототип / макет, данные — пример» |
| 12 | Хронометраж | 6 мин 30 с на 11 слайдов (таблица в конце). Допустимо 5–7 минут |

Обозначения в ASCII-макетах: `[H]` — заголовок-вывод, `[#]` — цифра-акцент, `[T]` — таблица, `[V]` — схема/график/скрин, `[QR]` — QR-код, `[SRC]` — источники, `[!]` — плашка «Гипотеза/Допущение/Симуляция», `[N]` — номер слайда.

## Слайд 4. Решение

**Заголовок:** Покупатель видит цену 1,40 млн ₽ по статьям до оплаты и получает документ на каждом из 11 этапов сделки

**Ключевая мысль:** мы не держим деньги за машину и не прячем наценку: цена раскладывается по статьям до договора, деньги за машину — в банке покупателя, наш доход виден одной строкой.

**Раскладка:**
```
┌──────────────────────────────────────────────────────────────┐
│ [плашка] РЕШЕНИЕ                                             │
│ [H] Покупатель видит цену 1,40 млн ₽ по статьям до оплаты    │
│     и получает документ на каждом из 11 этапов сделки        │
│                                                              │
│ ┌────────────┐ ┌────────────┐  ┌──────────────────────────┐  │
│ │ [V] экран  │ │ [V] экран  │  │ [#] 1 403 740 ₽          │  │
│ │ 02 Карточка│ │ 04 Трекинг │  │ диапазон 1,28–1,53 млн ₽ │  │
│ │ цена по    │ │ этапы и    │  │ [T] 4 строки раскладки   │  │
│ │ статьям    │ │ «где деньги»│ ├──────────────────────────┤  │
│ │            │ │            │  │ Защита денег (дословно)  │  │
│ └────────────┘ └────────────┘  │ [!] Гипотеза Г-11        │  │
│ «Прототип / макет,             ├──────────────────────────┤  │
│  данные — пример»              │ До → После (3 строки)    │  │
│                                └──────────────────────────┘  │
│ Секретный соус: не технология, а проверяемый процесс (1 стр.)│
│ [SRC]                                            [QR] [N]4   │
└──────────────────────────────────────────────────────────────┘
```

**Тексты блоков:**

*Цифра-акцент:* «1 403 740 ₽ — пример цены под ключ во Владивостоке: Япония, 3–5 лет, 1 496 см³, до 160 л.с. Диапазон с учётом курса ±10% — 1,28–1,53 млн ₽ [1][Допущение]».

*Мини-таблица раскладки* (4 строки + итог):

| Статья | ₽ |
|---|---|
| Машина, расходы в Японии, фрахт | 1 000 000 [Допущение] |
| Пошлина и утильсбор | 251 240 [2][3] |
| Оформление: брокер, СВХ, СБКТС/ЭПТС, платёжный агент | 92 500 [4][Допущение] |
| Наша комиссия | 60 000 |
| **Итого во Владивостоке** | **1 403 740** |

*Блок «Где ваши деньги»* (текст ставить **дословно**, без сокращений и перефразирования):
> «До отгрузки деньги в вашем банке на аккредитиве. В пути машина застрахована и оформлена на вас. Вторую половину комиссии мы получаем, только когда вы забрали машину».
>
> Подпись мелко: «Схема согласуется с банком» + плашка «Гипотеза Г-11».

*Блок «До → После»* (сторителлинг Андрея, 3 пары):
- «Было: цена „примерно“ → Стало: расчёт по 7 статьям с источником и датой до договора».
