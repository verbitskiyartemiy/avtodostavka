# Wireframe 03 — Отчёт о состоянии (аукционный лист с переводом)

Для слайдов: 4 (Решение: показ продукта); 9 (Гипотеза Г-10: хватит ли разобранного листа для Японии).

> Шаг S10, скилл `dk-wireframes`, платформа mobile (38 символов ≈ 375 px). Дата: 25.09.2026. Основано на `information-architecture.md` и `user-story-map.md`. Экран — **целевой продукт (Release 2)**; в MVP (Release 1) те же данные клиент получает от оператора в чате (`user-story-map.md`). Модели, пробеги, даты и оценки на экране — **[пример данных]**, не реальные лоты. Цифры цены — из примера сделки `unit-economics.md` (курс ЦБ на 24.09.2026).

**Контекст:** клиент выбирает японскую машину до торгов (из карточки) или смотрит отчёт внутри сделки (этап 3).
**Цель пользователя:** понять, битая ли машина, не видя её вживую, и решить — брать или нет.
**Истории:** US-105 (Япония), US-106 (Корея, Китай — тот же экран с отчётом партнёра: фото, толщиномер, диагностика), US-008 (макет для интервью в R0).

### Аннотации

| # | Элемент | Поведение |
|---|---|---|
| 1 | Источник отчёта | Кто составил: аукцион (Япония) или партнёр по осмотру (Корея, Китай), дата. Для партнёра — имя сервиса и чек на стоимость осмотра |
| 2 | Итог | Простыми словами: «можно брать / не брать / торговаться» и сколько заложить на ремонт. Итог даёт оператор по правилам, а не «на глаз» [ДОПУЩЕНИЕ: правила — в чек-листе оператора] |
| 3 | Оценка | Общая и салон + «Что значат оценки» (шкала аукциона простыми словами) |
| 4 | Схема кузова | Метки повреждений с расшифровкой под схемой. Нажатие на метку → фото этого места, если есть |
| 5 | Замечания | Перевод рукописных пометок аукциона |
| 6 | Фото | Галерея + исходный лист как есть (чтобы опытный клиент проверил перевод) |
| 7 | Честная оговорка | Лист составляет аукцион; видео и замеры ЛКП — отдельной платной услугой по себестоимости (если Г-10 не подтвердится — это становится обязательной строкой, как для Кореи) |
| 8 | «Беру» | До торгов — подтвердить максимальную ставку (US-109); кнопка активна, только если аккредитив открыт (US-108) |
| 9 | «Не беру» | Отказ после отчёта — депозит возвращается (`unit-economics.md`, условия возврата) → новые варианты |

### Вариант для Кореи и Китая

Те же блоки, но вместо схемы аукциона — отчёт партнёра по чек-листу (US-107): толщина ЛКП по деталям, компьютерная диагностика, фото VIN и пробега, история (для Кореи — страховые случаи). Итог — «брать / не брать / торговаться».

### Состояния

- **Отчёт не готов:** «Осмотр заказан, партнёр пришлёт до ДД.ММ».
- **Итог «не брать»:** кнопка 8 скрыта, вместо неё «Показать похожие».
- **Нет фото:** «Аукцион не приложил фото — можно заказать видео (платно)».

### Переходы

- «Беру» → подтверждение ставки → 04 Трекинг (этап 4–5).
- «Не беру» → 01 Лента с похожими.
